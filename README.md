# 💡 Pixel Brightness

노트북 화면과 외부 모니터 밝기를 **한 번에** 조절하는 Windows용 도트(픽셀) 스타일 밝기 조절기예요.

![screenshot](docs/screenshot.png)

<img src="docs/icon_on.png" width="96"> <img src="docs/icon_off.png" width="96">

## 기능

- **0~100% 밝기 바**: 드래그, 마우스 휠, 방향키로 조절하면 밝기가 실시간으로 바뀌어요.
- **노트북 화면과 외부 모니터 동시 조절**
- **설정 저장 3칸 (1P / 2P / 3P)**: 자주 쓰는 밝기를 저장하고 한 번에 불러와요.
- **작업표시줄·바탕화면 우클릭 빠른 설정**: 창을 열지 않고 저장해 둔 밝기로 바로 바꿔요.
- **밝기에 따라 바뀌는 전구 아이콘**: 0~100%까지 11단계예요.
- **8비트 효과음**: 왼쪽 위 ♪ 버튼이나 `M` 키로 켜고 꺼요.
- **적용 / 취소**: 취소하면 창을 열기 전 밝기로 돌아가요.

## 설치

1. 오른쪽 위 **Code → Download ZIP**으로 내려받아 원하는 폴더에 압축을 푸세요. 예: `C:\Users\<내이름>\PixelBrightness`
2. 폴더 안의 **`install.bat`**을 더블클릭하세요.
3. 바탕화면에 생긴 **"밝기 전환"** 아이콘을 더블클릭하면 창이 열려요.

> 설치한 뒤에는 폴더를 옮기지 마세요. 옮겼다면 `install.bat`을 다시 실행하면 돼요.

### 작업표시줄에 고정하기

바탕화면의 "밝기 전환" 아이콘을 우클릭한 뒤 **작업 표시줄에 고정**을 누르세요. 그다음 창을 한 번 열었다 닫으면 우클릭 빠른 설정 목록이 생겨요.

### 바탕화면 우클릭 메뉴

Windows 11에서는 **Shift + 우클릭**을 하거나 우클릭 후 **"추가 옵션 표시"**를 누르면 저장한 설정이 보여요.

## 단축키

| 키 | 동작 |
|---|---|
| ← / → | 1%씩 |
| ↑ / ↓ | 10%씩 |
| 휠 | 5%씩 |
| 1 / 2 / 3 | 저장한 설정 불러오기 |
| M | 소리 켜기/끄기 |
| Enter | 적용 |
| Esc | 취소 |

## 외부 모니터에 대해

외부 모니터는 Windows 화면 출력 색을 어둡게 하는 방식(감마 조절)으로 밝기를 바꿔요. 모니터마다 밝기 명령(DDC/CI) 지원이 제각각이라서, 이 방식이 모든 모니터에서 작동해요.

- Windows 기본 설정에서는 외부 모니터가 **약 50%까지만** 어두워져요. 더 어둡게 하려면 **관리자 권한 PowerShell**에서 아래 명령을 실행한 뒤 재부팅하세요.
  ```
  reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM" /v GdiIcmGammaRange /t REG_DWORD /d 256 /f
  ```
- 모니터 자체 밝기(OSD 메뉴)는 **100**으로 맞춰 두는 걸 추천해요.
- 절전 모드에서 깨어나면 외부 모니터 밝기가 원래대로 돌아갈 수 있어요. 그럴 땐 저장한 설정을 한 번 눌러 주세요.

## 제거

폴더 안의 **`uninstall.bat`**을 실행하면 밝기를 100%로 되돌리고, 바로가기와 우클릭 메뉴를 지워요. 그다음 폴더를 삭제하세요.

## 요구 사항

- Windows 10 / 11
- 별도 프로그램 설치 필요 없음 (Windows 기본 PowerShell 5.1 사용)
